# CLT Layer fall off model

This project aims to simulate the fire-induced CLT layer fall-off in heat transfer analysis, based on general-purpose finite element software ABAQUS and Python.

This work has been published **'CLT Layer Fall-Off under Fire: Numerical Models and Probabilistic Analysis'** by Tongchen Han and Tesfamariam Solomon in Journal of Structural Engineering-ASCE. DOI: 10.1061/JSENDH.STENG-16401.

An illustrative example for conducting layer fall-off simulation in ABAQUS is provided.
